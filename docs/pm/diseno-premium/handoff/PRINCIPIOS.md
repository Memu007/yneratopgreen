# Principios y anti-principios

Estos criterios son obligatorios para implementar **B — Mesa de negocios**.
Si una decisión visual contradice uno de ellos, no pertenece al sistema aunque
se parezca a las capturas.

## Principios

1. **La operación antes que la decoración.** Precio, condición, ubicación,
   disponibilidad, vendedor y próxima acción forman la jerarquía principal.
2. **Autoridad sin solemnidad.** La tipografía editorial da gravedad; la grilla,
   los bordes y el lenguaje directo mantienen el producto operativo.
3. **Confianza demostrable.** Sólo se muestran estados respaldados por datos del
   producto. La interfaz no insinúa validaciones que TopGreen no hizo.
4. **Densidad legible.** Hay más información útil y menos contenedores. El
   espacio separa relaciones; no se agrega una tarjeta para cada bloque.
5. **Un mercado, cuatro anatomías.** Activo de alto valor, insumo, servicio y
   logística comparten sistema, pero no fingen que se compran igual.
6. **Escala internacional desde la estructura.** Moneda, unidades, territorio,
   fechas y lenguaje son datos configurables; Argentina es el formato inicial,
   no una rigidez embebida en la composición.

## Anti-principios

- Verde + beige + hoja como atajo de “agro”.
- Hero fotográfico con copy aspiracional que desplaza el inventario.
- Mosaico de tarjetas redondeadas y flotantes para todo.
- Iconos lineales genéricos usados para llenar vacíos.
- Degradados verdes, glassmorphism, brillos o sombras de SaaS.
- Métricas, sellos, estrellas o urgencia sin respaldo real.
- La misma CTA para maquinaria, una bolsa de insumo y un servicio.
- Interfaces que sólo funcionan con fotografías perfectas.
- Español con anglicismos de producto (`listing`, `deal`, `checkout`) cuando hay
  una expresión clara para el usuario.

## Test anti–AI slop

Antes de aceptar una pantalla, responder:

1. ¿Podría cambiarse el nombre por cualquier agtech sin que cambie el diseño?
2. ¿Hay un adorno que no informa estado, jerarquía ni acción?
3. ¿Se está usando una tarjeta para evitar resolver la composición?
4. ¿La confianza depende de una afirmación que el sistema no puede probar?
5. ¿Las cuatro clases de operación terminaron visual y funcionalmente iguales?

Un solo “sí” obliga a revisar. El sistema se reconoce por la mesa editorial,
la densidad comercial y las diferencias operativas, no por una paleta sola.
