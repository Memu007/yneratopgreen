## Restricción de uso de imágenes

Las láminas de `assets/` son evidencia de exploración interna. No son diseños
finales, fotografías licenciadas para catálogo ni activos reutilizables por la
aplicación. Pueden contener detalles de maquinaria inventados por generación de
imagen. Deben reemplazarse por UI construida y fotografía real con licencia
comprobada durante el handoff aprobado.
