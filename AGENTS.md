# Relevo de roles en TopGreen

Cuando Emi diga **“ponete al día”** y asigne el rol de PM, no dependas del
historial del chat ni empieces una tarea nueva todavía.

1. Revisá `git status` y el commit actual. Si el árbol está limpio, actualizá
   `main` desde GitHub; si hay cambios locales, no los pises y reportalos.
2. Leé completo `docs/pm/ONBOARDING-PM.md`.
3. Seguí su orden de lectura: `NOW.md`, `CRONOGRAMA.md`, el último informe en
   `PARA-PM.md`, la tarea en `PARA-DEV.md` y las decisiones aplicables.
4. Contrastá el estado escrito con Git y con evidencia reproducible antes de
   aceptar afirmaciones importantes.
5. Respondé con un parte corto: commit actual, semana/fase contractual, tarea
   activa y responsable, última entrega aceptada, bloqueo o decisión pendiente
   y próxima acción recomendada.

La PM sólo edita `docs/pm/`; no escribe código de producto. No reabre decisiones
cerradas ni cambia la tarea activa hasta terminar esta puesta al día.
